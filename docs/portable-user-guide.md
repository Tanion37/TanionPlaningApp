# TanionPlaning — руководство пользователя (portable)

Документ для человека, который впервые открывает приложение. Описывает **десктоп-планировщик** (portable-сборку без Telegram-бота).

**Где лежит portable:** `C:\CURSOR\TanionPlaning-portable\`  
**Запуск:** `TanionPlaning.exe`  
**Данные:** `data\tasks.xlsx` рядом с exe (задачи сохраняются автоматически).

Python на компьютере не нужен. Копируй всю папку целиком (`TanionPlaning.exe` + `_internal` + `data`).

---

## 1. За 2 минуты: базовый цикл

1. Запусти `TanionPlaning.exe`.
2. Откроется экран **Задачи дня** (главный).
3. Нажми круглую кнопку **+** справа — создай задачу (обязательно только название).
4. Перетащи задачу в нужный раздел или на кружок тега внизу.
5. Чтобы отметить сделанное: возьми кисть **✅** (справа) и кликни по задаче, либо перетащи задачу на **✅**.

Всё остальное — разные способы смотреть и раскладывать те же задачи.

---

## 2. Что такое задача

Задача — прямоугольник **200×50**. На карточке:

- сверху (если есть) — **проект**;
- ниже — **символы тегов** и **название**.

### Поля (двойной клик по задаче → правка)

| Поле | Зачем |
|------|--------|
| Название * | Единственное обязательное |
| Проект | Группировка; клик по имени проекта на карточке фильтрует только этот проект |
| Описание | Текст для себя |
| Дата постановки | Когда завели |
| Можно приступать (`start`) | С какой даты задача «активна» |
| Надо закончить (`due`) | Дедлайн |
| Напоминание + время | Дата/время напоминания (для бота; в portable само напоминание не шлётся) |
| Периодичность | каждый день / неделю / месяц / год – новая копия на завтра с тегом «входящая». Пока открыт экземпляр серии, следующий не появится. Отмена последнего останавливает серию. |
| Кто поставил | Автор |
| Теги | Включаются значками в диалоге или с доски |

### Цвет текста

| Цвет | Когда |
|------|--------|
| Серый | Отложенная, старт в будущем, выполнена/отменена |
| Оранжевый | Важная **и** срочная |
| Красный | Важная (без срочной) |
| Зелёный | Есть дедлайн в будущем и нет даты старта |
| Чёрный | Остальные |

### Цвет рамки

| Цвет | Когда |
|------|--------|
| Оранжевый | Важная + срочная |
| Синий | Важная |
| Зелёный | Актуальная |
| Серый | Остальные / закрытые |

## 3. Экраны

Переключение:

- кнопки **◀** / **▶** по краям;
- свайп влево/вправо по пустому месту доски;
- клавиши **←** / **→**.

Имена экранов сверху. Порядок слева направо:

| № | Экран | Суть |
|---|--------|------|
| 1 | **Логи** | История изменений за ~14 дней (выполненные / изменённые) |
| 2 | **Списки** | Простые колонки-чеклисты (не задачи из xlsx) |
| 3 | **Задачи дня** | Главный рабочий экран дня |
| 4 | **ГОРИТ / ДЕЛАЕМ** | Раскладка по сроку старта: ГОРИТ → ДЕЛАЕМ → ЗАВТРА → НЕДЕЛЯ → ТУМАН ВОЙНЫ |
| 5 | **По срочности** | Просроченные → Сегодня → Неделя → Прочие → Беклог |
| 6 | **По тегам** | Колонки по смысловым тегам |
| 7 | **По проектам** | Колонки по проектам |

Выполненные и отменённые с обычных досок скрыты (их видно через фильтр/логи/кисть ✅ 🗑).

---

## 4. Экран «Задачи дня» (главный)

Три зоны:

### Входящие (слева)

Сюда попадают задачи, которые уже можно делать (`start` пустой или ≤ сегодня), но ещё не помечены как **актуальная**.

Перетащи задачу из входящих в **Горит / Нужно / Можно** — она станет актуальной и получит приоритет.

### Горит / Нужно / Можно (центр)

Только **актуальные** задачи:

| Раздел | Что выставляется |
|--------|------------------|
| **Горит** | актуальная + важная + срочная |
| **Нужно** | актуальная + важная (без срочной) |
| **Можно** | актуальная без важной/срочной |

Можно: перетащить задачу в раздел **или** кликнуть заголовок раздела (режим «кисти») и кликать по задачам.

### День (справа)

Колонки по тегам дня (счётчики). Удобно раскладывать «что ещё висит» по смыслу.

Кнопка **⬇** «Всё во входящие» на этом экране возвращает актуальные (кроме «горит») обратно во входящие.

---

## 5. Экран «ГОРИТ / ДЕЛАЕМ»

Колонки — не просто ярлыки: **перетаскивание в колонку меняет даты/статус**.

| Колонка | Эффект drop |
|---------|-------------|
| **ГОРИТ** | `due` = сегодня, `start` ≤ сегодня |
| **ДЕЛАЕМ** | `start` = сегодня (как кнопка «Сег») |
| **ЗАВТРА** | `start` = завтра |
| **НЕДЕЛЯ** | `start` = +7 дней |
| **ТУМАН ВОЙНЫ** | как **отложенная**: старт +1 месяц, сброс due/remind, снятие важная/срочная |

---

## 6. Теги и действия

### Нижняя полоса кружков

Каждый кружок — тег. Два способа:

1. **Перетащи задачу на кружок** → тег (или спец-действие) применяется.
2. **Кликни кружок** → режим **кисти** (курсор-рука): следующие клики по задачам включают/выключают этот тег. Повторный клик по тому же кружку снимает кисть. Повторный клик той же кистью по той же задаче — отмена (undo).

Кружки в полосе можно **перетаскивать между собой**, чтобы поменять порядок.

### Правая панель (круги)

| Значок | Действие |
|--------|----------|
| **+** | Новая задача |
| **⛶** | Полный экран (прячет верхнюю панель) |
| **↻** | Перезапуск в полном экране |
| **↶** / **↷** | Отменить / повторить |
| **✅** | Выполнена (+ дата выполнения) |
| **🗑** | Отменена |
| **Сег** | Как колонка ДЕЛАЕМ |
| **З** | Как ЗАВТРА |
| **Нед** | Как НЕДЕЛЯ (+7 дней) |
| **🗄** | Отложенная (беклог) |
| **💬** | Переписка: старт через неделю |
| **Aa** | Режим надписи: следующий клик на доске → текст |
| **▢** | Режим прямоугольника: протяни область |
| **⬇** | Всё во входящие (на экране дня) |

Кисть с правой панели работает так же: клик по кнопке → клики по задачам.

### Справочник тегов

| Символ | Тег | Смысл |
|--------|-----|--------|
| ⚠ | важная | Приоритет |
| 🔥 | срочная | Срочность |
| ⬇ | входящая | Ещё не разобрана на день |
| ★ | актуальная | В работе сегодня (Горит/Нужно/Можно) |
| ☑ | проверенная | Проверка |
| 🎲 | геймдизайн | Тема |
| ПРО | ПРОГД | Тема |
| 🐸 | сложная | «Лягушка» |
| ⚡ | быстрая | Быстро сделать |
| 📄 | документная | Документы |
| 💳 | финансы | Платежи |
| 💡 | обдумываемая | Подумать |
| 🚶 | уличная | Вне дома/офиса |
| 🏠 | личная | Личное |
| 🤖 | ИИ | С ИИ |
| 💬 | переписка | Ждёт ответа / переписка |
| 📤 | делегируемая | Отдать другому |
| 👁 | контроль | Контроль (+ старт завтра) |
| 🗄 | отложенная | Беклог / туман |
| 🔧 | в работе | Уже делаю |
| 🗑 | отменена | Снята |
| ✅ | выполнена | Закрыта |

## 7. Создание и правка

- **+** или двойной клик по задаче.
- В диалоге теги включаются кликом по значкам.
- Кнопки проектов под полем «Проект» подставляют уже использованные имена.
- Пустые даты можно очистить (кнопка сброса у поля даты).

В **ДЕМО**-режиме создание и правка отключены.

---

## 8. Фильтры и навигация

- **Клик по названию проекта** на карточке → показать только этот проект. Повторный клик / **Сбросить фильтр** / **Esc** — сброс.
- **Esc** также: выйти из режима надписи/прямоугольника; выйти из полного экрана.
- **Delete / Backspace** — удалить выделенную надпись или прямоугольник на доске.

---

## 9. Списки и логи

**Списки** — отдельные колонки в том же `tasks.xlsx` (лист списков). Клик по пустому месту колонки → добавить пункт. Это не задачи планировщика.

**Логи** — журнал: что выполнено и что менялось по дням. Удобно вечером посмотреть день.

---

## 10. Полный экран и демо

- **⛶** — рабочий режим «только доска + кнопки».
- **ДЕМО** (кнопка на экране) — набор шуточных задач без записи в файл. Повторный клик выключает.

---

## 11. Где что хранится

| Путь | Содержимое |
|------|------------|
| `data\tasks.xlsx` | Задачи и списки |
| Рядом с приложением / в `%LOCALAPPDATA%` (в зависимости от сборки) | Порядок тегов, аннотации, логи активности |

Бекап: скопируй папку `data\` (как минимум `tasks.xlsx`).

---

## 12. Типичные сценарии

**Утро.** Экран «Задачи дня» → разбери **Входящие** в Горит/Нужно/Можно → остальное раскидай по тегам дня или отложи **🗄**.

**Сделать сейчас.** Задачи в «Горит» и «Нужно»; готовые — кистью **✅**.

**Перенести на завтра.** Кисть **З** или drop в колонку ЗАВТРА на экране triage.

**Отложить на месяц.** **🗄** или ТУМАН ВОЙНЫ.

**Найти всё по проекту.** Клик по проекту на любой карточке.

**Ошибочно кликнул.** **↶** (отмена).

---

## 13. Чего в portable нет

- Telegram-бота и утренних сводок в мессенджер.
- Общего облака: каждый ПК со своей копией папки — свои данные, пока сам не скопируешь `data\`.

Сборка portable: на машине разработчика  
`powershell -File scripts\build_portable.ps1` → снова `C:\CURSOR\TanionPlaning-portable`.
