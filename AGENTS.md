# Cursor: TanionPlaningApp

Публичный **снимок** десктоп-планировщика. Личных данных, токенов и клиентов нет.

Рабочая копия с задачами и ботом: соседний репозиторий `TanionPlaning`. Ежедневный запуск и правки – оттуда. Сюда копируется только пакет `app/` (`scripts/sync_public_app.ps1`).

## Запуск снимка (без личных задач)

1. Python 3.11+ (`py -3 --version`).
2. `py -3 -m pip install -r requirements.txt`
3. Из корня репозитория: `py -3 -m app`

Данные: `data/tasks.xlsx` (создаётся пустым при первом запуске). Каталог `data/` не коммитить.

## Правки

Не править этот репозиторий как основное дерево. Источник – `TanionPlaning/app/`. Не подмешивать секреты, `config.json`, чужие xlsx/json с задачами.
